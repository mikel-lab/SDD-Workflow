# Main-owned SDD design

SDD is defined by eight guarantees, not fixed role choreography. Main owns intake/spec/plan/implementation/verification. Main has no skill-prescribed model or effort; Reviewer alone is mandatory and independent/read-only.

Normal planning is validated and frozen before edits. Independent planning review is required only for nine defined risk categories or Main escalation, never bypassed when triggered. A changed planning baseline revalidates/reclassifies; normal task repair does not impose universal review. Final independent integrated review is required in every cycle. Main corrects, verifies and same Reviewer rechecks delta/impact; material changes require full applicable review. Proven Reviewer loss permits documented replacement/full pending scope; timeouts/compaction do not.

Local state/events/evidence live apart from SpecKit's frozen artifacts and inventory. The schema and read-only validator represent risk, criterion/task/check coverage, actual versions, owner bounds, reviews/findings and recovery. Missing approvals cannot be invented from summaries. Checkpoint is the committed head of immutable candidate events. Hashes check local integrity, not authenticity or semantic dependency sufficiency.

Existing validate_cycle isolation/source/inventory guards remain. Product snapshots capture real tracked/untracked and required ignored inputs plus file metadata; pinned base/dirty content are distinguished from staging-only changes. Only exact active artifact/control files and declared safe outputs are excluded, even with colocated roots. Workspace/source/dependency exclusions and unsupported coverage fail.

SpecKit produces official artifacts. Superpowers provides compatible conditional execution practices, no parallel planning/user gate, fixed model ladder or mandatory per-task subagents. Additional delegation is useful bounded work with explicit non-overlapping writer ownership including Main. Main alone dispatches.

Distribution ships only Reviewer. Exact retired profiles are backed up/removed; unmanaged files, source isolation, archival privacy/authority and separate status are preserved. Global installation, publication and merge are separate outcomes from local validation.
